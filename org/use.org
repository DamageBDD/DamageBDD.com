#+TITLE: Use DamageBDD
#+DESCRIPTION: Open the DamageBDD dashboard, run a feature through the API, or set up your own node.
#+INCLUDE: "header.org"

* Open the dashboard

Use the [[https://run.damagebdd.com][DamageBDD dashboard]] for account, execution and
wallet workflows. This documentation site does not request wallet signatures or
create payment invoices.

#+BEGIN_EXPORT html
<p><a class="button" href="https://run.damagebdd.com">Open dashboard ↗</a></p>
#+END_EXPORT

* Run a feature through the API

The [[file:manual.org][user manual]] covers authentication, feature execution and
integration with your development workflow. The
[[https://run.damagebdd.com/api-docs/][API reference]] describes the hosted API.

Check the [[file:modules/index.org][module reference]] for supported steps and
[[file:pricing.org][pricing]] before running a workload.

* Operate your own node

Start with the [[file:install.org][installation guide]], then read the
[[file:node.org][node overview]] and [[file:node_admins.org][administration guide]].
The [[file:articles/features_current.org][component map]] records implementation
and validation scope; it is not a live health check for a deployment.
